## Decided
- Implement monitoring as passive-only: no connection prompts and no traffic blocking.
- Use existing 10-second snapshot refreshes rather than adding a separate polling mechanism.
- Expose network data through a backward-compatible `net_procs` snapshot field using `serde(default)`.
- Defer domain-name resolution because it would require DNS inspection and likely a larger extension-level design.
